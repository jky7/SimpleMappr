Remote imports accept public HTTP and HTTPS URLs on standard ports. Every redirect and DNS address is checked. TLS certificates are verified. Imports are limited to 5 MiB and 15 seconds including DNS. Upload local files instead of fetching localhost or private addresses.

Use input_format to declare CSV, WKT, GeoJSON, KML, GeoRSS or SimpleMappr settings. Use encoding for legacy text encodings. POST files to /import for parsed editor groups, or to /api for a rendered map. Settings JSON and GeoJSON are separate formats.

Web Feature Service (WFS)

{{ url }}/wfs/?SERVICE=WFS&VERSION=1.0.0&REQUEST=GetCapabilities

Web Map Service (WMS)

{{ url }}/wms/?SERVICE=WMS&VERSION=1.1.1&REQUEST=GetCapabilities

WMS supports 1.1.1 and 1.3.0. For 1.3.0, EPSG:4326 uses latitude,longitude BBOX order. CRS:84 uses longitude,latitude order. Include STYLES even when empty. WFS supports 1.0.0, 1.1.0 and 2.0.0 with a maximum of 1000 features. Use MAXFEATURES before WFS 2.0 and COUNT for WFS 2.0. Service errors return XML.
